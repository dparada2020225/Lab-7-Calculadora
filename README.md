# Lab 7 - Calculadora

Calculadora web desarrollada con React + TypeScript + Vite.

## 🔗 Links

- **App:** https://lab-7-calculadora-production.up.railway.app
- **Repo:** https://github.com/dparada2020225/Lab-7-Calculadora

## ✨ Funcionalidades

- Operaciones: suma, resta, multiplicación, división, módulo
- Punto decimal
- Toggle de signo (+/-)
- Límite de 9 caracteres en el display
- Muestra ERROR para resultados negativos o mayores a 999,999,999
- División con decimales largos truncados a 9 caracteres (ej. 22/7)

## 🛠️ Stack

- React 19 + TypeScript
- Vite
- Vitest + Testing Library
- Storybook 10
- ESLint (JavaScript Standard)

## 🚀 Correr localmente

```bash
npm install --legacy-peer-deps
npm run dev
```
